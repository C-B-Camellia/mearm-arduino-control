# 五点速度执行链、输出对照与最短实机A/B

## 执行器与实验范围

LINE/POLY/CURVE共用drawGoal→sampleGoal→execute→requestPose→applyPendingPose。预检、浮点和整数位置限位、J1+J2=148..250、单一Servo所有权均保留。
原段时间=max(描线最小1ms或其他10ms, ceil(关节最大差*1000/60), 空间段长*1000/FEED)，控制输出20ms；自动路径非描线阶段也保留其原时间规则。实验仅在POLY/CURVE的STROKE移除第二项，其他阶段及LINE不变，仍受空间FEED。循环有界推进几何节点、每控制周期最多提交一帧，必经顶点等待输出确认；这不是物理位置反馈。

POLY P2/P3/P4在输出确认后各保持80ms；编译期MEARM_POLY_HOLD_MS可对照60/100。CURVE没有这些顶点停顿。固定保持只保证指令保持，不证明物理到点。不引入曲率前瞻或新轨迹公式。

## 最短实机步骤（需用户批准烧录后自行执行）

1. 记录所选Git SHA、环境、HEX哈希；仅编译命令：pio run -e uno_nano_link 或 pio run -e uno_nano_five_fast。不可将uno环境误当D10版。PC115200；Nano TX→Uno D10、共地，接线保持现状。不在本文执行上传。
2. 先STATUS确认限位/标定及当前安全姿态；TEACH START后摇杆J3不应变化，TEACH EXIT恢复。显式PC J3仍允许，不用它做自动夹笔测试。
3. 普通工作模式B2，等3秒ARMING后录制简单小幅动作，约12秒再次B2，STATUS应REC Ready且时长约12秒，10秒提示应出现。若无响应，记录PC REC STOP结果与完整输出；不要用反复乱按掩盖丢事件。B3回放，暂停/恢复，再B4 HOME；记录第一条错误及姿态，不以关节边界反复冲击测试。
4. 重新确认真实纸面高度、五点和夹笔姿态；不要把本文坐标/高度硬编码成新标定。默认DRAW SHAPE N在原P1/P2薄矩形应ERR GEOMETRY且不运动。若纸面范围允许，可测试显式DRAW SHAPE N 106.56 -29.16 159.81 26.37（这些来自已有五点包围框，不代表障碍物路径已实测）。
5. 保持同点集和FEED25，标准版与实验版分别DRAW LINE/POLY/CURVE。保存LIST、STATUS、CMD、PATH VALID/DONE及外部计时。然后用户确认供电/机械正常后再把FEED逐步调高作另一组试验，例如FEED80；切回LINE比较时恢复原已通过FEED，避免把全局FEED变化误归因于实验开关。
6. POLY记录P2/P3/P4纸面过点误差和抖动，实验版默认保持80ms；CURVE不应三次明显停顿。练习B1暂停、B2继续、B3取消抬笔HOME。出现供电跌落、碰撞、异常载荷立即停止测试。
